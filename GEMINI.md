# Claqueta

Lee `AGENTS.md`: ahí están las reglas, el orden de lectura y los comandos.

Gemini CLI no carga skills por sí solo. Cuando el encargo nombre un documento de `library/`, ábrelo como archivo de contexto y síguelo. Empieza por `library/hyperframes/skills/hyperframes/SKILL.md`, que dirige al resto.

Usa las herramientas gratuitas de `tools/`. Este sistema no necesita una llave de Gemini para nada: voz, música, efectos, tiempos y render corren en local.
